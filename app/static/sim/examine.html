How this is done
  1. the address is parsed and reduced to the registered name, the part somebody buys
  2. seventeen measurements are computed from the name alone, with no lookups
  3. a logistic-regression model scores those measurements and returns a probability
  4. the strongest contributions become the reasons, each tied to a measurement above
Every value on this page comes from the model's own response: the address it was given, the seventeen measurements it computed, the probability it returned and the reasons drawn from those measurements. The pacing is designed. The content is not.
