About

A small, honest detector

Nyavu is Swahili for fishing net. The project asks a narrow question: can a web address that nobody has reported yet be judged from its text alone, and can the judgement be explained well enough that a non-specialist understands it?

What it does

You paste a link. It reduces the address to its registered domain, measures seventeen characteristics, and scores it with a logistic-regression model trained on 17,730 addresses. It returns a risk band, a score, and the reasons that moved the score. It never opens the destination, so the site you are checking never learns you looked.

The number, and why it is 75%

Published phishing detectors often report accuracy above 97%. Many of those figures come from a quiet data fault: the legitimate addresses were collected as bare domains while the phishing addresses were collected as full hosts. A model trained on that learns "has a subdomain, therefore phishing" instead of learning phishing.

An early version of this project reached 95.7% that way. Once the fault was removed, it fell to 63%. The deployed model scores 75.4% accuracy with an F1 of 0.740 on a domain-disjoint hold-out set, and that is the number reported everywhere in this project.

A 19.8% false-positive rate is unusable in front of a person, so the deployed system adds a reputation rule: a domain inside the Tranco top 100,000 is never flagged on name evidence alone. The cost is stated rather than hidden — phishing hosted on a popular domain is missed.

What it cannot do

  • It judges names, not pages. A phishing page on a compromised legitimate site will pass.
  • It decays. Tactics change; retraining on a schedule is required, not optional.
  • The brand list is a curated reference, not a verified registry of official domains.
  • A verdict is an assessment, never a guarantee of safety.

How it is built

Python throughout: scikit-learn for the pipeline, FastAPI for the service, SQLite for storage, and a hand-written front end with no build step, so nothing can fail to compile in front of an examiner. A browser extension and an Android agent use the same public API. Accounts are optional; scan history belongs to the signed-in user and is never shown to anyone else.

Privacy

No page is fetched, no browsing is monitored, and no notification access is requested — that permission was considered and rejected as disproportionate. Passwords are stored as salted PBKDF2-SHA256 hashes. Anonymous scans are counted but never displayed to another visitor.

The project

Built by Donald Enron, Justus Kibet, Ian Mazigulu and Allan Kibet for COMP324 at Kabarak University, Department of Computer Science and Information Technology. Source is available on GitHub.
